# Interface Web Flask

Site destiné à présenter les événements, la galerie de photos et les mesures de batterie enregistrés.

- `templates/` : pages HTML et gabarits Jinja.
- `static/` : styles, scripts et ressources statiques.

Les images capturées seront servies depuis un stockage configuré sur le Raspberry Pi, et non automatiquement ajoutées au dépôt Git.
