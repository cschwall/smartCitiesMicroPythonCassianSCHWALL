# Réseau

[Retour à l'accueil](../README.md)

## Objectif

Regrouper les exercices de connexion et de communication réseau en MicroPython sur Raspberry Pi Pico W.

## Laboratoires

- **[Labo 5 — Horloge connectée et profilage énergétique](labo05_horloge_connectee/)** : connexion Wi-Fi, synchronisation NTP, conversion de l'heure en angle, commande d'un servomoteur et mesure de consommation avec PPK2. Le [README du labo](labo05_horloge_connectee/README.md) présente le câblage, les programmes, les tests validés et les limites des modes de veille.

## Organisation

Chaque laboratoire conserve son propre sous-dossier et son README. Un laboratoire mobilisant plusieurs thèmes (ici réseau, PWM et profilage énergétique) est documenté dans un seul dossier principal.

Les identifiants Wi-Fi sont stockés dans un fichier `wifi_config.py` privé, non versionné.
